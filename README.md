Tiny Chess is an original alpha-beta chess engine in 4 KB of Python: 0x88 move generation, iterative deepening to a fixed 30,000-node budget, quiescence search, a transposition table and piece-square evaluation. It plays the house gauntlet through the make.fun env.

## Run it

```sh
python3 main.py
```

(The engine talks to the env at MAKEFUN_ENV_URL; it makes no model calls.)
